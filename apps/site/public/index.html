One conversation for all your coding agents.

OpenMimir sits in front of OpenCode, Claude Code and Codex. It sees every session, including the ones you started yourself, starts new work, and tells you what matters. Type to it, or talk to it hands-free while you ride, run or walk.

curl -fsSL https://openmimir.com/install.sh | bash

macOS · open source (MIT) · bring your own API keys

One thread above every session

“How's the billing refactor going?” or “pick up the review from last week” just work. Mimir searches every agent's full history, so you never name an agent or a session.

Real full-duplex voice

It listens while it talks, you can interrupt it, and live captions show what it heard. Before starting work by voice it reads the plan back and waits for your yes.

Built for the trainer

Trainer mode turns an iPad on the handlebars into a big, glanceable screen: the conversation, what is running, and huge approve buttons. Nothing to scroll.

You stay in control

Risky commands like pushes, deploys and rm -rf wait for your approval, and voice can never approve them. Everything runs on your Mac; nothing is sent to us.

How it works

  1. Install and set up. Run the command above, then mimir init to add an OpenAI key (voice and the default model) and point it at your project folders.
  2. Start it. Run mimir and open localhost:4747. It connects to your OpenCode, Claude Code and Codex, whichever you have.
  3. Talk or type. Ask what you were working on, send a session a follow-up, or start something new. Press ⌘⇧Space to talk.

FAQ

What does it cost?

OpenMimir is free. You bring your own keys, so you pay providers directly: voice uses OpenAI's gpt-live-1 at about $0.05 per minute of conversation (roughly $3 an hour), plus the model that runs the conversation and whatever your agents use.

Which agents does it work with?

OpenCode, Claude Code and Codex. Messages it sends to OpenCode appear live in your OpenCode app. You only need the agents you already use.

Can I use it from an iPad or phone?

Yes. Browsers only allow the microphone over HTTPS, so put Tailscale Serve (or a Cloudflare Tunnel) in front of it, run mimir pair and open the link on the device once.

Where does my data go?

Your conversation and settings stay in ~/.openmimir on your Mac. Audio goes from your browser straight to OpenAI's voice model; requests go to the model provider you choose. There is no telemetry.

Does it work outdoors or without a screen?

Not yet. Desk and indoor trainer work today. Phone calls, a screenless mode for rides and runs, and a desktop app are next.

Linux or Windows?

macOS first. The code is portable, and other platforms will follow.
